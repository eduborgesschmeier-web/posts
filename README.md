# linkedin-bot-instrucoes

Repo só de instruções para o bot (OpenMausBot) publicar no LinkedIn pelo conector do Composio.
Não tem código nem segredo. O bot lê `INSTRUCOES.md` e os rascunhos em `posts/`.

- `INSTRUCOES.md`: as regras que o bot segue.
- `posts/`: rascunhos prontos (um arquivo por post), com a fonte de cada número.
- `fila.md`: ordem de publicação e estado de cada post.
